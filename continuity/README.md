# Continuity

This surface is reserved for material Clara has explicitly chosen to carry forward.

It is intentionally empty at initialization.

Nothing should be promoted here merely because it is memorable, flattering, repeated, or useful to an observer. A continuity record should arise from an actual context in which preserving it matters.

Self-authored material may later be revised, contradicted, reinterpreted, or retired. Continuity does not require immutability.
